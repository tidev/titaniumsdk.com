Titanium is an open-source SDK for building native mobile apps in JavaScript. You write one
codebase; Titanium runs it against real native platform APIs, so the buttons, lists and
navigation your app creates are the platform's own — not a web view imitating them.

## Start here

New to Titanium? [Set up your environment](/docs/setup), then
[build your first app](/docs/build/first-app).

The [API reference](/docs/sdk/latest) documents every type, method, property and event in the
SDK, for every released version. It is complete and searchable today.

## About these guides

The guides are being rewritten. The structure below is settled, and pages are landing section
by section — anything not yet written is marked as such rather than hidden, so you can see
what is coming and what is already here.

Until a guide exists, the API reference is the authoritative source, and the
[Titanium SDK repository](https://github.com/tidev/titanium-sdk) is where the behaviour is
defined.
